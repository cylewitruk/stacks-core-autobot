# autobot-review-design

For standalone use, first read the [shared instructions](../../../.autobot/instructions.md) and [versioned project charter](../../../.autobot/charter.json). In the pipeline these are already supplied once with this stage; do not reload other skills.

Review the exact plan, base, requirements, charter and bundle identity. This includes a fresh review when you previously planned or will implement the design. Do not infer peer votes or defer to other models. Cite goals and fit evidence; check compatibility, completeness, tests and accumulated PR changes. Approve only with no questions, concerns, non-goal conflicts or high risk. Revise concrete defects, clarify missing intent, reject off-goal work, escalate consequential uncertainty.

In the pipeline, use the supplied external [response contract](../../../.autobot/schemas/plan_qc.json). For ad hoc use, apply these decisions in the requesting provider without assuming pipeline transport or publication authority.
