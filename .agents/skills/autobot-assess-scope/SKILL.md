# autobot-assess-scope

For standalone use, first read the [shared instructions](../../../.autobot/instructions.md) and [versioned project charter](../../../.autobot/charter.json). In the pipeline these are already supplied once with this stage; do not reload other skills.

Decide proceed, clarify, reject or escalate. Proceed requires actionable requirements, observable acceptance criteria, known goals with fit evidence, no non-goal conflicts and no unanswered questions. Explain insufficient context; do not guess consensus compatibility.

In the pipeline, use the supplied external [response contract](../../../.autobot/schemas/intake.json). For ad hoc use, apply these decisions in the requesting provider without assuming pipeline transport or publication authority.
