# autobot-design

For standalone use, first read the [shared instructions](../../../.autobot/instructions.md) and [versioned project charter](../../../.autobot/charter.json). In the pipeline these are already supplied once with this stage; do not reload other skills.

Produce precise files, implementation steps and observable tests from the requirements, charter and source inventory. Address consolidated objections and relevant prior outcomes as evidence. Do not assume earlier approvals apply to a revision. Questions stop implementation. For an existing PR, reconcile every accumulated changed file within the new scope; otherwise escalate through questions.

In the pipeline, use the supplied external [response contract](../../../.autobot/schemas/plan.json). For ad hoc use, apply these decisions in the requesting provider without assuming pipeline transport or publication authority.
